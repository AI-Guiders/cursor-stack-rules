# Workspace snippets

Product-specific rules (CASA dialogue gates, HCI cards, refactor conventions tied to one repo)
belong in that product workspace `.cursor/rules/`, not in cursor-stack-rules.

Examples (keep in product repos):
- `casa-dialogue-emergence-gate.mdc` → casa-ontology-payload / PCF workspace
- `casa-hci-knowledge.mdc` → when KB layout is workspace-specific
- `refactor-clean-csharp.mdc` → optional per C# monorepo convention
